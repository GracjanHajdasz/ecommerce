# E‑Commerce Project 🛒

> Fullstack aplikacja e‑commerce stworzona w celach edukacyjnych.

Projekt pokazuje umiejętności tworzenia aplikacji webowej typu e‑commerce z frontendem React i backendem Node/Express.  
**Status:** W TRAKCIE — niektóre funkcje są jeszcze w budowie.

---

## 📌 Funkcje

### ✔️ Działające

- Podstawowe endpointy backend API

### ⏳ W trakcie

- Logowanie / rejestracja użytkownika
- Koszyk zakupowy
- Panel admina
- Historia zamówień

### 🔜 Planowane

- Integracja z płatnościami
- Filtrowanie i sortowanie produktów

## 🚀 Uruchomienie lokalne

### 1. Sklonuj repo

```
git clone https://github.com/GracjanHajdasz/ecommerce.git
cd ecommerce
```

### 2. Backend

```
cd backend
npm install
npm start
```

### 3. Frontend
```
cd frontend
npm install
npm start
```
